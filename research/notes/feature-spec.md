### 0.3 Dia (brief)

Dia (Browser Company, Chromium, public since 2025) started with a Chrome-like **horizontal tab strip** and an AI chat sidebar; ⌘T opens an AI/search box rather than Arc's command bar. After Arc-user backlash it added a **vertical-tabs "sidebar mode"** (View menu toggle, v0.36 mid-2025; shipped in v1.3.x Oct 2025), a **pinned-tab grid** (Oct 2025) and tab groups (Dec 2025). It has **no Spaces**: separation is by Profiles opening in separate windows. Common complaints from Arc users: no Spaces, loss of the fuzzy ⌘T command bar, no sidebar data import, Apple-silicon-only. What it kept: sidebar/vertical tabs, pinned tabs, the general Arc visual language. ## A. Sidebar model

**Key insight.** The sidebar is not a tab strip plus bookmarks; it is a single ordered tree of *entries*. An entry is either **permanent** (Essential / Pinned / Folder) or **temporary** (Today tab). Every entry may or may not have a live page behind it. Bookmarks do not exist as a separate concept: "bookmark" = permanent entry; "open it" = load its page *in place*.

### A.1 Entry types and states

| Type | Where | Persistent | Has stored URL | Auto-archives | Icon-only |
|---|---|---|---|---|---|
| Essential | grid at top, per Profile (shared across the Profile's Spaces) | yes | yes | never | yes |
| Pinned | list under space title, per Space, may live in Folders | yes | yes | never | no (favicon + title) |
| Folder | pinned section only (v1) | yes | — | never | — |
| Split group | either section (pinned if any member pinned) | as its members | per member | as Today if all members temporary | — |
| Today tab | below the separator, per Space | until archived/closed | no | yes | no |

Each permanent entry stores: `id`, `storedURL`, `storedTitle` (user label if renamed, else last page title at pin time), `storedFavicon` (data URL), `containerId` (from its Space's Profile), `spaceId` (null for essentials), `folderId`, `position`, `customIcon` (emoji/SDF icon, optional), `createdAt`, `lastActiveAt`.
Live state (not persisted beyond session): `isLoaded`, `currentURL`, `currentTitle`, `isChanged = currentURL != storedURL` (normalised: ignore trailing slash and `#fragment`; `?query` differences DO count), `isAudible`, `isMuted`, `isLoading`.

States of a permanent entry:
1. **Unloaded** (Zen `pending`): no web content process. Rendered at 60% opacity favicon, title in secondary colour. Clicking loads `storedURL`.
2. **Loaded, at stored URL**: normal rendering.
3. **Loaded, changed** (Zen `zen-pinned-changed`): a 6px dot badge at the favicon's bottom-right and, on hover, a **reset button** replacing the favicon (Zen: `.tab-reset-pin-button`). Hover tooltip/sublabel: "Back to pinned URL"; with ⌘ held: "Separate from pinned tab" (keeps the current page as a new Today tab and resets the entry; Arc's ⌘-click behaviour).

### A.2 Click behaviours

| Gesture | Essential | Pinned | Today |
|---|---|---|---|
| Click | select (load `storedURL` if unloaded) | same | select |
| Click on an already-selected entry | if changed → **reset to storedURL** (Arc: "reset by clicking its icon"); else no-op | same | no-op |
| ⌘-click on selected changed entry | reset + open the current page as a new Today tab | same | — |
| Middle-click | unload if loaded; if already unloaded → no-op (never deletes an essential) | unload if loaded; if already unloaded → **unpin & remove** (Zen `wheel-close-if-pending`) | close |
| Double-click title | rename inline | rename inline | rename inline |
| Hover | show reset button only if changed | show reset button if changed, else nothing (no X on pinned) | show X close button at right |
| Right-click | context menu (A.8) | | |

### A.3 ⌘W on a permanent entry (Zen `reset-unload-switch`, default)
1. Focus moves to the most-recently-used *other* tab in this Space (fallback: next Today tab; if none, create a blank Today tab and open the command palette).
2. Any Peek/Glance child of the entry is closed first.
3. The page is **unloaded** (web process discarded, session history serialised so Back still works after reload).
4. The entry is **reset** to `storedURL` so the next load starts clean. The entry stays in the sidebar.
⌘⇧W / "Remove" in the context menu actually removes a permanent entry (confirm only if it is a Folder with ≥1 children). Preference (hidden, `sidebar.permanentCloseBehavior`: `reset-unload-switch` | `unload-switch` | `reset-switch` | `switch` | `reset` | `close`) mirrors Zen.

### A.4 Navigation inside a permanent entry
- Same-site navigation (same eTLD+1) happens in place and marks the entry *changed* once the URL differs from `storedURL`.
- A click that would leave the site (different eTLD+1, top-level navigation, not a redirect chain started by the stored site) opens in **Peek** (section I.6) rather than replacing the page (Arc Peek; Zen `zen.tabs.open-pinned-in-new-tab` + `glance.open-essential-external-links`). Form posts, OAuth redirects, and `window.location` set by the page within 2s of a user gesture are exempt (they navigate in place) to avoid breaking logins.
- Setting: Links ▸ "Open links to other sites from pinned tabs in Peek" (on by default).

### A.5 Reset / edit stored URL
- "Reset to pinned URL" (context, click on selected changed entry, unbound shortcut `pinned.reset` by default — same as Zen) → navigate to `storedURL` with a 150ms favicon crossfade back to `storedFavicon`.
- "Replace pinned URL with current" → `storedURL = currentURL`, `storedFavicon` = current favicon; toast "Pinned URL updated".
- "Edit pinned URL…" → inline popover with a URL field prefilled with `storedURL`; Enter validates with the fixup (adds scheme) → toast "Pinned URL updated" or inline error "That doesn't look like a valid URL."

### A.6 Folders
- Folders only in the pinned section in v1 (Arc allows folders anywhere; Zen allows in both — we restrict to reduce archive edge-cases). Max nesting depth 5 (Zen `zen.folders.max-subfolders`).
- Create: "+" menu ▸ New Folder; context on a pinned entry ▸ "Move to Folder ▸ New Folder…"; multi-select ≥2 pinned entries → context "New Folder with N tabs"; drag one pinned entry onto another and hold 500ms (**not** the 20% edge zones, which reorder).
- Collapsed folder with an active child shows the child "peeking" directly under the folder row (Arc/Zen `folder-active`).
- Hover a folder header 500ms → **folder preview popover** with a search field ("Search {folder}…", first result auto-selected, Enter opens, Esc closes). Drop-target zone = middle 60% of the row height (Zen: 20% top/bottom reserved for reorder).
- Context: Rename…, Change Icon…, New Subfolder…, Unload All Tabs, Copy All Links, Paste URL as New Tab, Convert to Space, Move to Space ▸, Unpack (flatten children into parent), Delete (confirm if non-empty; children become pinned entries of the parent).

### A.7 Today tabs, archive, separator
- Today tabs sit below a 1px separator row with a right-aligned "Clear" text button (visible when ≥1 Today tab). "Clear" (⌘⇧K) closes all Today tabs in the Space with a staggered slide-out (30ms per row, max 300ms total) and toast "Tabs closed · Undo" (button restores; 8s).
- **Auto-archive**: a Today tab whose `lastActiveAt` is older than the Profile's "Archive tabs after" (options **12 hours (default), 24 hours, 7 days, 30 days**; Arc confirms only 12h default — the option list is our choice) is removed from the sidebar on the next sweep (every 10 min while idle, and at launch) and written to the **Archive** with `{url, title, favicon, spaceId, archivedAt}`. Never archives: selected tab, audible tab, tab with unsaved form input (beforeunload listener), tabs in a split with a permanent member. Archive is per Profile, browsable (Section H), restorable.
- Opening a link from a Today tab opens a new Today tab directly below it (Firefox `insertRelatedAfterCurrent` behaviour).
- Closing a Today tab selects the MRU tab in the Space (Zen `select-recently-used-on-close`), not the neighbour.
- Closing the last Today tab leaves the pinned/essential selection; if nothing is selectable, show the empty-state content ("Press ⌘T to search or type a URL") instead of a new-tab page.

### A.8 Context menu (tab entry)
Today tab: Pin (⌘⇧D) · Add to Essentials (N/12) · Move to ▸ [Spaces…, Favorites] · New Folder with Tab · Split with… ▸ [current tab, pick…] · Duplicate · Rename… · Change Icon… · Copy URL · Copy URL as Markdown · Reload · Mute/Unmute · Unload · Archive Below · Close Tabs Below · Close Other Tabs · Close (⌘W).
Pinned entry: Unpin (⌘⇧D) · Add to Essentials · Move to ▸ · Move to Folder ▸ · Pinned URL ▸ [Reset (unbound), Replace with current, Edit…] · Split with… · Duplicate · Rename… · Change Icon… · Copy URL · Copy URL as Markdown · Reload · Mute · Unload · Remove.
Essential: Remove from Essentials · Pinned URL ▸ … · Rename… · Change Icon… · Copy URL · Reload · Mute · Unload.

### A.9 Drag & drop (converts type by target section)
- Essentials grid ⇄ pinned list ⇄ Today list: dropping across a boundary converts the entry (Today→Pinned sets `storedURL=currentURL`; Pinned→Today drops stored state but keeps the live page; →Essentials requires `count < 12`, otherwise the grid shows a shake + badge "12/12" and the drop is refused). Dragging an entry to another Space's icon at the bottom switches Space after 500ms hover and drops it into that Space's matching section.
- Within a list: reorder with a 2px accent insertion line; the dragged row lifts (scale 1.03, shadow) and others animate with 150ms ease-out. ⌥-drag duplicates (Arc).
- Text/URL from outside the window dropped on the sidebar: URL → new Today tab at the drop position; plain text → new search tab (Arc).
- Dragging an entry **out** of the sidebar beyond 40px past the window edge opens it in a new window at the drop point, keeping its type (Arc).
- Multi-select: ⌘-click toggles, ⇧-click ranges, within one section only; drag moves the whole selection; ⌘W/⌘⇧D/Move to/New Folder act on the selection.
- Haptic tick (NSHapticFeedbackPerformer, `.alignment`) when the insertion line changes position (Zen/Arc).

## B. Spaces

- Space = `{id, name, icon (emoji or SF Symbol), theme {colors[] (1–3), algorithm, opacity, texture}, profileId, pinnedEntries[], todayTabs[], position}`. Essentials belong to the Profile and are shown in every Space that uses the Profile (Zen `separate-essentials`); switching to a Space with a different Profile crossfades the essentials grid.
- Creation: "+" ▸ New Space, or swipe past the last space (edge action), or command "New Space". Form: name field (placeholder "Space Name"), icon picker, colour picker (3 colour wells, "Click to add a color", algorithm segmented control: Complementary / Split / Analogous / Triadic / Floating), Profile dropdown (default "Default"; tooltip "Profiles are used to separate cookies and site data between spaces"). Enter creates; Esc cancels.
- Switching: click a space icon at the bottom; ⌃1…⌃9 (⌃0 = 10th); ⌘⌥← / ⌘⌥→ (wrap-around); two-finger horizontal swipe over the sidebar (threshold 25% of sidebar width, velocity-assisted, rubber-band at the ends, swiping past the end reveals the "new space" form); ⌃+scroll-wheel; command palette "Focus on {space}". Animation: both the outgoing and incoming tab lists slide horizontally by 100% over 250ms (ease-out), the window tint crossfades over the same 250ms, the space icon row's active indicator slides. Reduced-motion: crossfade only.
- Active indicator: the space icons sit centred in the footer; the active one is enlarged (1.15×) and shows its name as a label to the right of the icon row only while hovering the row.
- Space title row (above pinned list): name + chevron to collapse the pinned section (Arc); click the name to rename inline; "…" on hover → the space context menu.
- Space context menu: Change Name…, Change Icon…, Edit Theme…, Set Profile ▸, Reorder Spaces (enters a drag-reorder mode on the icon row), Unload Space, Unload All Other Spaces, Space Routing Settings…, Delete Space (dialog "Delete {name}? This cannot be undone."; on confirm its pinned entries and Today tabs are moved to the Archive; routes targeting it are deleted).
- Containers: each Profile has its own cookie jar; a tab always uses its Space's Profile; moving a tab to a Space with a different Profile reloads it in the new container (dialog once: "Logins and cookies won't carry over").
- **Space routing** (Arc ATC / Zen): rules `{match: contains | equals | regex, pattern, targetSpaceId}` evaluated on *external* link opens and on links opened from a different Space when "route links" is on; default for external links: Most Recent Space (v1 has no Little Arc). Toast "Opened in {space}" with "Switch" button. Tab context: "Add route for domain…".
- Deferred: per-Space Profile *creation UI* beyond "Default" and one extra is in v1; profile sync, shared spaces, live folders are out of scope.

## C. Address bar / command palette

- One component, two entry points:
  - **⌘T — New**: opens the palette centred over the content (Zen floating urlbar, 640px wide, top 18% of the content area), empty, placeholder "Search or enter URL…". No new-tab page is created until commit (Zen `replace-newtab`). Commit opens a **new Today tab** (Enter), or in the **current tab** (⌘Enter, mirrors Arc's "Enter in ⌘L"), or background (⇧Enter? no — see table). Esc closes without a tab.
  - **⌘L — Edit**: same palette prefilled with the current tab's full URL, fully selected. Enter navigates the **current tab** (Enter with unchanged text = reload, Arc). ⌘Enter opens in a new tab. Esc restores.
  - Clicking the compact URL field in the sidebar header behaves as ⌘L but keeps the input docked in place (Zen `floating-on-type` + `focusedViaMousedown`).
  - Pressing ⌘T/⌘L while the palette is open closes it (Arc).
- Sidebar header shows **domain only** (Zen `show-domain-only-in-sidebar`) with the site icon button on the left (site panel: permissions, tracking protection, extensions) and a **Copy URL** button on hover at the right; hovering reveals the full URL in a tooltip after 600ms.
- Suggestion groups (ordered, max 8 visible, ↑/↓ to move, Tab to cycle groups): 1) **Top hit** (URL autocomplete / exact tab match / Paste & Go if clipboard holds a URL), 2) **Open tabs** across all Spaces (icon + title + space name chip; Enter switches, ⌘Enter opens a copy), 3) **Pinned & essentials** (across Spaces; Enter switches to the Space and selects the entry; ⌘Enter opens a copy), 4) **History** (frecency), 5) **Search** with the default engine, 6) **Commands** (Tab from an empty query, or prefix `>`): the Zen action list (A–Z): Add to Essentials, Capture Screenshot, Clear Archive, Close Tab, Copy URL, Copy URL as Markdown, Duplicate Tab, Find in Page, Focus on {tab/space}, Move to {space}, New Folder, New Space, New Split View, Next/Previous Space, Open Private Window, Pin/Unpin Tab, Print, Reload / Reload without cache, Reopen Closed Tab, Reset Pinned Tab, Settings, Space Routing…, Switch to Light/Dark/Auto appearance, Toggle Sidebar, View Archive, Unsplit, Unload Tab.
- Site search keywords: `yt ` + Tab enters "Search YouTube" mode (chip on the left; Backspace on empty exits). Engines manageable in Settings ▸ Search.
- ⌥Enter: open in a new *background* tab. ⇧Delete / ⌘⌥Delete on a history suggestion removes it; hover shows an × on the right.
- Typed-but-uncommitted text persists per tab for 45s (Zen `wait-to-clear`).
- When the sidebar is hidden: the palette still floats centred (it does not depend on the sidebar); the compact URL field is not visible, so ⌘L is the only edit entry. A thin **status pill** bottom-left shows link targets on hover (1.5s → full URL; dodges the cursor).
- Find in page: ⌘F opens a bar at the top-right of the content (not inside the palette); ⌘G / ⌘⇧G next/prev; Esc closes; match count "3 of 12".

## D. Split view

- Max **4** panes (Arc & Zen). Layouts: `hbox` (side by side, default for 2), `vbox` (stacked), `grid` (2×2 for 3–4). Per-split ratios persisted.
- Create: ⌘⇧= (Arc ⌃⇧+ is awkward; we bind ⌘⇧= and keep ⌃⇧= as alias) adds an empty pane to the right and focuses the palette inside it; drag a sidebar entry onto another entry's row centre (hold 500ms) → "Join" (Arc/Zen); drag an entry into the content area → drop-zone overlay with 4 edge targets (left/right/top/bottom, 40px activation band) and a centre target (replace); multi-select entries → context "Join N tabs"; context "Split with…"; ⌥-click the current entry duplicates it into a split (Arc); Peek ▸ Split button.
- Sidebar representation: one **group row** containing the member favicons (and titles when ≥2 lines fit) separated by 1px dividers; the focused pane's segment is tinted. Clicking a segment focuses that pane. ⌥-click the group row separates all (Arc). The group row sits in the pinned section if any member is permanent, else in Today.
- Keyboard: ⌘⌥G/V/H change layout (Zen), ⌘⌥U unsplit (keeps all as separate entries, focused one selected), ⌃⇧1…4 focus pane N (Arc), ⌃⇧] / ⌃⇧[ next/prev pane, ⌘W closes the focused pane only (if the pane is a permanent entry, apply A.3 to that entry and remove it from the split; a 1-pane split collapses to a normal entry).
- Pane chrome: on hover a 24px top strip appears with the pane's domain, a drag grip (reorder panes by dragging), "Change layout" and × buttons. Resizer between panes: 7px hit area, 1px visual, double-click resets to equal.
- URL bar reflects the **focused pane** (focus follows click or keyboard; hover does not change focus by default — Zen has it as an option).
- Links opened from a pane open as Today tabs (not new panes); Peek from a pane overlays the whole content area.

## E. Sidebar show / hide

- ⌘S toggles the sidebar (Arc; Zen compact mode). State persisted per window.
- Hidden mode = Zen compact mode with `hide-tabbar=true`: the content area expands to the full window; the window keeps a 10px inset floating sidebar when revealed (`--zen-compact-float`).
- **Hover reveal**: moving the mouse into a 4px band at the left edge (right edge if sidebar is on the right) and resting for 150ms (60 ms since B-114, 2026-10-21) slides the sidebar in as a **floating overlay** (does not push content) over 250ms (180 ms since B-114) with a blurred/vibrant backdrop. It stays while the pointer is inside it or any popup/menu/palette anchored to it is open, and hides 150ms after the pointer leaves it (Zen `sidebar-keep-hover.duration`), with a tolerance of 200px horizontal / 100px vertical when the pointer leaves the window (Zen `outside-window-edge-offset.*`) so moving to the Dock doesn't collapse it. ⌘⌥S pins the overlay open until the next ⌘⌥S/⌘S or a click in web content (Zen `show-sidebar`).
- Traffic lights: in normal mode they live in the sidebar header; ~~when hidden they are drawn in a 38px floating cluster top-left that fades out after 2s of no pointer movement near it (hover reveals)~~. **Amended 2026-10-21 (B-114, the user; done in 5.1b):** no floating cluster: hidden, the sidebar takes the traffic lights with it; they fade in as the revealed overlay slides in under them and out as it leaves. The reveal arrives sooner instead: a 60 ms dwell in the band (was 150 ms) and a 180 ms slide (was 250 ms; out 150 ms). The window remains draggable from the top 5% of content (Zen `drag-window-from-content`).
- Where do navigation buttons go? When hidden, there is **no persistent toolbar**: Back/Forward/Reload are keyboard (⌘[ ⌘] ⌘R), trackpad swipe, and present in the revealed overlay header. Optional "Show toolbar" (View menu) adds a 36px top toolbar with ◀ ▶ ↻, full URL, extensions — like Arc's toolbar and Zen's multi-toolbar layout.
- Drag the sidebar splitter to < 120px → it snaps closed, enters hidden mode and shows once: toast "Sidebar hidden — press ⌘S to bring it back" (5s) (Zen).
- Sidebar width range 180–500px (Zen max 500), default 240px; width persisted. Sidebar side: Settings ▸ "Tabs on the right".
- In hidden mode, events that would otherwise be invisible produce toasts: new background tab opened ("New background tab opened"), new Space created, download complete.

## F. Bottom bar and toasts

Footer (40px) of the sidebar, left→right:
1. **Library / downloads button**: a down-arrow icon; during a download it becomes a circular progress ring; on completion it bounces (spring, 0.5s) and shows a count badge until the popover is opened. Click → popover listing downloads (name, size/progress, Cancel ×, Open in Finder on hover, "Clear" link); right-click → Open Library. New download animation: the clicked link's favicon flies on an arc from the click point into this button (1000ms, end scale 0.45) (Zen).
2. **Space icons** centred (B).
3. **"+" button** → menu: New Tab (⌘T), New Folder, New Split (⌘⇧=), New Space. Double-click empty sidebar area = new tab (Arc).
Audio: when a tab is audible and not selected, a compact media row (favicon, title, play/pause, ×) appears above the footer (Arc Audio Player; Zen media controls).

Toasts: anchored bottom-centre of the **sidebar** when visible, else bottom-left of the window; 1 at a time (same id replaces with a pop), spring in (bounce 0.2, 0.5s), auto-dismiss 2s (hover pauses; 5s for toasts with a button), fade+scale out 0.2s. Content: icon + 1 line + optional button. ## H. Tab lifecycle & memory

- **Loading on launch**: only the selected tab per window loads; everything else (pinned, essentials, Today) is restored *unloaded* with title+favicon from the session (Firefox `restore_pinned_tabs_on_demand=true` semantics). Essentials used in the last 24h may preload lazily after idle 5s (Arc "smarter loading for Favorites").
- **Discard rules** (independent of archive): a loaded, non-selected, non-audible, non-PiP tab with no unsaved-form flag is discarded (process dropped, session history + scroll position kept) when: idle > 60 min (Today) / > 3 h (pinned/essential), or memory pressure (macOS `DISPATCH_MEMORYPRESSURE_WARN`) → discard least-recently-used first across all Spaces, never the selected tab or tabs playing audio (Zen TabUnloader patch rules). Discarded tabs render dimmed; reload on click restores scroll.
- Manual: "Unload" (tab), "Unload Space", "Unload All Other Spaces", "Unload All Tabs" (folder).
- **Archive**: see A.7. Archive view (Library ▸ Archived): list grouped by day, each row: favicon, title, domain, Space chip, "Restore" (returns to its Space as a Today tab at the top), ×; search box; "Clear Archive" with confirmation. Archived items also surface in the palette's History group with a chip "Archived".
- **Session restore**: whole sidebar tree (spaces, entries, order, stored URLs, live URLs, scroll positions, split layouts, which entry is selected per Space) is written atomically every 15s when dirty and at quit; rolling backups: last 10 of today, 1/day for 10 days, 1/week for a month, 1/month for a year (Arc). Help ▸ Restore Sidebar… lists them.
- Crash recovery: on relaunch after a crash restore the same state but all tabs unloaded.

## I. Details that make it feel great

1. **Animations**: tab row insert/remove = height 0→28px + fade, 150ms ease-out; selection pill slides between rows (spring 0.35s); space switch slide 250ms; palette open = scale 0.96→1 + fade 120ms; Peek open = scale from the link's rect to the card 350ms (Zen `animation-duration`); toasts spring; all honour `prefers-reduced-motion` (crossfade instead).
2. **Favicons**: cached per origin in `storedFavicon`; essentials show the icon at 20px inside a 36px squircle whose background is the icon's dominant colour at 15% (Zen `essentials-favicon-bg`); missing favicon → first letter of the domain on a hashed colour; custom emoji/symbol icons override; while loading, the favicon spot shows a 2px ring spinner (no throbber in the title area).
3. **Titles**: entry label = `customLabel ?? currentTitle ?? storedTitle ?? domain`; pinned entries keep their label stable when `isChanged` (show current title as a secondary dimmed line only on hover); titles never show "(1)" counters — unread badge counts are extracted and shown as a small dot.
4. **Hover states**: row background at 6% foreground; close × fades in on the right for Today tabs (28px hit area, never shifts the title); for changed pinned entries the favicon swaps to the reset icon on hover with the sublabel "Back to pinned URL" / "Separate from pinned tab" (⌘).
5. **Audio**: audible tab shows an animated equaliser over the favicon; click it to mute (speaker-slash stays); muted tabs show a static slashed speaker; context "Mute". Media row at the bottom when the audible tab is not selected.
6. **Peek** (Arc Peek / Zen Glance): overlay card 86% width/height centred with 24px rounded corners, backdrop dimmed 30%; header with domain, "Open as tab" (⌘O), "Split" , ×; Esc/click outside/⌘W closes; the Peek is a real tab in the Today section only while open (hidden from the list); expanding converts it into a Today tab under the parent.
7. **Drag & drop of content**: URL text → tab at drop position; multiple URLs → multiple tabs; image/file → opens as tab; dropping on a Space icon adds there. Text selection dragged → search tab.
8. **Changed dot**: 6px accent dot bottom-right of the favicon when `isChanged` (replaced by the reset icon on hover); essentials show the dot at the squircle's corner.
9. **Rename**: double-click or Enter on a focused row → inline text field with current label selected; Enter commits, Esc cancels, empty resets to page title; row pulses 1→0.98→1 on commit.
10. **Right-click menus**: as in A.8, B, F; all menu verbs match the palette's command names so users learn one vocabulary.
11. **Overflow indicator**: when the selected entry is scrolled out of view, a 2px accent line at the top/bottom edge of the list; clicking it scrolls to it (Arc).
12. **Window chrome**: vibrancy behind the sidebar tinted by the Space theme; inactive windows desaturate the sidebar 20%; mono (grey) traffic lights optional.
13. **Keyboard focus in sidebar**: ↑/↓ move, →/← expand/collapse folders, Enter selects, Space opens Peek of a pinned entry's stored URL, Delete = ⌘W.
14. **Status pill** bottom-left for link hover (600ms delay; 1.5s → full URL) that moves to the right side when the cursor approaches.
15. **Empty states**: no Today tabs → nothing (no placeholder rows); no essentials → a dashed slot with "Drag a tab here to make it an Essential" shown only on drag-over (Arc "no favorites" state).
